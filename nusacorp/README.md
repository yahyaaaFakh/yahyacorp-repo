# NusaCorp - React + Bootstrap (Vite)

Website company profile satu halaman: Hero carousel, About, Services, Works (dengan filter), Teams, Testimonials, Pricing, Blog, Contact.

## Cara menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:5173

## Build production

```bash
npm run build
npm run preview
```

## Struktur
- `src/data.js` : semua teks/data section (mudah diedit)
- `src/images.js` : daftar gambar
- `src/components/` : komponen tiap section
- `src/styles.css` : seluruh styling
